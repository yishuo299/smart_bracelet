# 框图代码（分段复制）

与工程器件一致，节点采用 **「型号 + 作用」**（例：DS18B20数字温度传感器）。本设计**未使用 DHT11、未接 MPU6050**。每一段可单独复制到 [Mermaid Live](https://mermaid.live)。

---

## 第 1 段 — 硬件拓扑（flowchart TB）

**用途**：展示 MCU 与外设连接关系。

```mermaid
flowchart TB
    subgraph MCU["STM32F103 主控"]
        CORE[内核与应用]
    end

    DS18["DS18B20数字温度传感器<br/>（体表体温）"] -->|1-Wire| CORE
    MAX30["MAX30102心率血氧传感器<br/>（光电法 PPG）"] -->|I2C| CORE
    AD82["AD8232心电采集前端<br/>（心电信号调理）"] -->|ADC/GPIO| CORE
    DS13["DS1307实时时钟芯片<br/>（年月日时分秒）"] -->|I2C| CORE

    CORE -->|SPI/8080 等| LCD_MOD["LCD液晶显示模块<br/>（人机界面）"]
    CORE --> KEY_IN["独立按键<br/>（菜单与设置）"]
    CORE --> LED_IND["LED指示灯<br/>（状态/报警）"]
    CORE --> BEEP_MOD["有源蜂鸣器<br/>（报警声）"]

    BLE["蓝牙透传模块<br/>（USART2 无线串口）"] <-->|USART2| CORE
    ASR["ASRPRO语音识别模块<br/>（语音播报/闹钟）"] <-->|UART| CORE

    TIM3["TIM3定时器<br/>（周期节拍）"] --- CORE
    TIM4["TIM4定时器<br/>（秒表计时）"] --- CORE
```

## 第 3 段 — 蓝牙阈值指令（sequenceDiagram）

**用途**：时序：上位机 → 蓝牙 → 中断 → 解析 → 写阈值。

```mermaid
sequenceDiagram
    participant Host as 手机或PC
    participant BLE as 蓝牙透传模块
    participant UART as USART2中断
    participant Parse as 命令解析
    participant Th as threshold数组

    Host->>BLE: 发送一行 TH: 指令
    BLE->>UART: 串口字节
    UART->>Parse: 收到换行则解析
    Parse->>Th: Driver_Set_Threshold
    Note over Th: 更新心率/血氧/体温限值
```

```mermaid
    ALM --> DRV

    DRV --> HAL

```

## 使用方式

1. 只画其中一张：复制对应 **一个** 代码块到 Mermaid Live。  
2. 若只要图体：打开 `diagrams` 下同名 `.mmd` 文件。  
3. 浏览器整页预览：`diagrams/mermaid_preview.html`（需联网）。
